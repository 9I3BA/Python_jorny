# КодиК — Платформа изучения Python

Веб-платформа для обучения программированию на Python для школьников. Включает интерактивные уроки, блочный редактор кода, систему прогресса, чат и инструменты для учителей и администраторов.

---

## Стек технологий

- **Backend:** Python 3, Flask, Flask-Login, Flask-SQLAlchemy
- **База данных:** SQLite
- **Frontend:** Jinja2, HTML/CSS, JavaScript (без фреймворков)

---

## Роли пользователей

| Роль | Описание |
|------|----------|
| `admin` | Управление пользователями, группами, выгрузка статистики |
| `teacher` | Создание заданий, проверка работ, оценки, заметки об учениках |
| `student` | Прохождение уроков, выполнение заданий, магазин аватаров |
| `parent` | Просмотр прогресса ребёнка, чат с учителем и администратором |

---

## Возможности

### Ученик
- Карта уровней с 15 модулями (150+ уроков)
- Блочный редактор кода с запуском и проверкой вывода
- Система опыта (XP), уровней и стриков
- Ачивменты за прогресс
- Магазин аватаров (кейсы и отдельные аватары за XP)
- Боевой пропуск с картой рангов
- Библиотека теории
- Задания от учителя
- Песочница для свободного кода
- Чат с учителем

### Учитель
- Список учеников и их прогресс
- Создание заданий (с прикреплением файлов, дедлайном, группой или индивидуально)
- Проверка работ, выставление оценок и комментариев
- Личные заметки об учениках
- Чат с учениками, родителями и администраторами

### Администратор
- Управление пользователями (создание, редактирование, удаление)
- Управление группами и привязка учеников к учителям
- Привязка родителей к ученикам
- Выгрузка статистики в CSV:
  - По отдельной группе
  - По всем ученикам
  - По работе учителя
- Чат с учителями и родителями

### Общее
- Тёмная и светлая тема (переключатель на всех страницах)
- Чат в реальном времени (опрос каждые 3 с)
- Индикаторы непрочитанных сообщений в боковой панели чата
- Поиск контактов по имени в чате
- Адаптивный дизайн (мобильные устройства)

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <url>
cd <папка проекта>
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Инициализировать базу данных

```bash
python init_db.py
```

> Создаёт базу данных с модулями, уровнями, ачивментами и демо-аккаунтом администратора.

### 5. Запустить приложение

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## API-эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| `POST` | `/api/messages` | Отправить сообщение |
| `GET` | `/api/messages?with=<id>` | Получить переписку с пользователем |
| `GET` | `/api/messages/unread-counts` | Количество непрочитанных по отправителям |
| `POST` | `/api/run-code` | Выполнить Python-код (песочница) |
| `POST` | `/api/submit-level` | Сдать уровень |
| `POST` | `/api/buy-case` | Купить кейс с аватаром |
| `POST` | `/api/buy-avatar` | Купить аватар |
| `POST` | `/api/equip-avatar` | Надеть аватар |
| `POST` | `/admin/user/<id>/edit` | Редактировать пользователя |
| `POST` | `/admin/user/<id>/delete` | Удалить пользователя |
| `GET` | `/admin/export/group/<id>` | CSV по группе |
| `GET` | `/admin/export/all-students` | CSV по всем ученикам |
| `GET` | `/admin/export/teacher/<id>` | CSV по учителю |

## Регистрация первого администратора

После инициализации базы (`python init_db.py`) создаётся администратор. Войдите под его данными и через панель администратора создайте учителей, группы и добавьте учеников.

Ученики и родители регистрируются самостоятельно через форму регистрации. Учителей и администраторов создаёт только администратор через панель управления.
